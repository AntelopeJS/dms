# Overview

When your frontend layer ships its own Vue ([Frontend layer](/docs/building/frontend-layer)), these are the composables it calls to talk to the DMS — the [table below](#the-toolkit) maps them to their chapters. Where the previous section, [Extending the dashboard](/docs/extending-the-dashboard/overview), is about _registering_ capabilities, this one is the _toolkit_ your components consume.

All are auto-imported by the base layers — call them from `<script setup>` or a composable; no import needed.

## The toolkit

| Chapter                                                                           | Composables                                                                                             |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| [Auth requests & permissions](/docs/frontend-composables/authenticated-requests)  | `useAuthFetch` (`$authFetch`/`useFetchAuth`), `usePermissions`, `useMultiAccount`, `useCurrentUser`, `useLogout`, `useSessionRecovery` |
| [Realtime & notifications](/docs/frontend-composables/realtime-and-notifications) | `useRealtimeTopic`, `usePageRealtime`, `useUserRealtime`, `useNotifications`                            |
| [Page context](/docs/frontend-composables/page-context)                           | `useSiteLayout`, `useCurrentModule`, `useIsOwner`, `useDmsDevReload`, `usePreferences`, `useFavoritePages`, page setup, …  |
| [UI toolkit](/docs/frontend-composables/ui-toolkit)                               | `useModal`, `useDrawer`, `useConfirm`, `useApiError`, `useExportJob`                                    |
| [Utilities](/docs/frontend-composables/utilities)                                 | i18n (`useTranslation`), leave guard (`usePageLeaveGuard`), onboarding                                  |

::warning
For any backend call, use **`useAuthFetch`** (`$authFetch` / `useFetchAuth`) — never a bare `$fetch`/`useFetch`. Only the authenticated wrappers attach the bearer token and recover from an expired session. See [Auth requests & permissions](/docs/frontend-composables/authenticated-requests).
::
