# Cell displays

A column renders its cells through its data type's formatter. `display` on `@Column` draws the grid cells (and the fields of [expandable rows](/docs/components/tables#expandable-rows)) another way: a member as an avatar and a name, a status as a tinted pill, three counters as a progress bar. The column keeps its `type` for its forms, filters, validation and exports, and one label, its `name`.

A display is a typed class, like a data type: its options are checked at compile time, and its formatter receives the whole row, so a cell can compose sibling fields.

## Usage

```ts [src/data-apis/job-runs.ts]
import { DefaultDisplays } from "@antelopejs/interface-dms/base/table-view";

@Listable()
@Column({
  name: "Status",
  type: new DefaultDataTypes.SelectType({ items: JOB_RUN_STATUSES }),
  filterable: true,
  display: new DefaultDisplays.StatusPillDisplay({
    tones: { healthy: "success", running: "info", degraded: "warning", failing: "error" },
    subField: "lastError",
    liveValues: ["running"],
  }),
  size: 220,
})
declare status: JobRunStatus;

@Listable()
@Column({
  name: "Steps",
  type: new DefaultDataTypes.NumberType({ min: 0 }),
  display: new DefaultDisplays.ProgressDisplay({
    doneField: "doneSteps",
    totalField: "totalSteps",
    errorField: "failedSteps",
  }),
})
declare doneSteps: number;
```

A field a display reads (`lastError`, `totalSteps`) must be `@Listable()` to reach the row; give it `isVisible: false` on its own `@Column`, or no column at all, to keep it out of the grid. `size` sets the column's default width in px (150 otherwise; the room left is spread in proportion).

## Built-in displays

Every class lives in `DefaultDisplays` (`@antelopejs/interface-dms/base/table-view`):

| Class                 | Options                                                                                                                                                                                                 | Draws                                                                              |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `IdentityDisplay`     | `avatarField` (image value or URL), `icon` (tile instead of an avatar), `subtitleField` (a [sub-line](#composed-sub-lines); a plain string is drawn as written) + `subtitleTone` (`dimmed`), `selfField` + `selfLabel` (tag of the signed-in user's row), `badges: [{ field, equals?, notEquals?, label, tone? }]`, `storage`, `emptyLabel` + `emptyIcon` (a row without a value) | Avatar or icon tile, the value as the name, a "You" tag, badges, a secondary line; "Automatic" and a robot tile for an empty row. |
| `TwoLineDisplay`      | `primaryField` (a row field's text in place of the value), `subField` (a [sub-line](#composed-sub-lines)), `subTone` (`muted`), `emptyLabel` (`—`)                                                                         | A primary line — the value in its column's format, an amount, a select's label — over a secondary line; no avatar. |
| `PillsDisplay`        | `labelKey` (a related row's label field, `name` by default), `exclusive: { field, label, icon? }` (one filled pill when the row's field is set), `emptyLabel`                                           | A list as outline pills; an unresolved relation id is skipped.                     |
| `RelativeDateDisplay` | `style` (`"relative"`, the default, or `"day"`), `tone`, `nowWithinMs` + `nowLabel`, `emptyLabel` + `emptyTone`, `soonWithinMs` + `soonTone`, `pastStyle` + `pastTone`, `byField` + `byLabel` (`{ date, name }`) | "2 hr. ago", "Active now", "In 5 days", "Sep 27 · by Camille".                    |
| `IndicatorDisplay`    | `onLabel`, `offLabel`, `onIcon`, `offIcon`, `onTone` (`success`), `offTone` (`dimmed`)                                                                                                                  | An icon and a word; on for a set flag or a non-empty list.                         |
| `StatusPillDisplay`   | `tones` (value → `Tone`, required; a value left out is neutral), `subField` (a [sub-line](#composed-sub-lines) under the pill), `subTone` (the pill's tone by default), `liveValues` (values with a pulsing dot)  | A tinted pill led by a dot; a select column's item label and icon name it.         |
| `ProgressDisplay`     | `doneField`, `totalField` (required), `errorField`                                                                                                                                                      | A bar of the items done and "31 / 44", failed items in red at its end; green once all are done. |
| `SparklineDisplay`    | `field` (a list of numbers, required), `tone` (`primary`)                                                                                                                                               | A small line chart ("last 30 days").                                               |
| `DurationDisplay`     | `unit` (`"ms"`, the default, or `"s"`)                                                                                                                                                                  | "910 ms", "1.8 s", "4 min 12 s".                                                   |
| `BytesDisplay`        | —                                                                                                                                                                                                       | "12 kB", "1.4 MB".                                                                 |
| `MonoDisplay`         | `copy` (a button copying the value)                                                                                                                                                                     | The value in the mono font: ids, codes, slugs.                                     |

Labels are `$`-prefixed i18n keys or literals. Cell tones (`tone`, `onTone`, `subTone`, a sub-line's `tone`…) are `default`, `muted`, `dimmed`, `highlighted`, `success`, `warning`, `error`, `info` and `primary`; the status pill, the sparkline and the identity badges take a `Tone` (`neutral`, `primary`, `secondary`, `success`, `warning`, `error`, `info`).

## Composed sub-lines

The secondary line of a cell — under a status pill (`subField`), under an identity's name (`subtitleField`), under a two-line primary (`subField`) — is a row field the server fills per row. It holds a `CellSublineValue`:

- a string: `$`-prefixed for an i18n key, else drawn as written — under an identity, always drawn as written, since it is usually data (an address, an id);
- a [composed text](/docs/components/display-blocks#composed-texts) `{ key, params }`, written in the reader's language with its amounts, dates and counts formatted for their locale;
- a `CellSubline`, `{ text, tone? }`: the text and the cell tone it is drawn in, for a line whose tone depends on the row ("Payment failed · retry Oct 10" in `error`, "Due Oct 28" in `muted`).

Nothing (`null`, `""`) draws no line. A line without a tone takes the display's (`subTone`, `subtitleTone`), else its default. The logic stays on the server, which knows the row's state; the column only names the field. `CellSubline` and `CellSublineValue` come from `@antelopejs/interface-dms/base/table-view`.

### An invoice status and what payment is doing about it

```ts [src/data-api/invoices.ts]
import { type CellSubline, Column, DefaultDisplays } from "@antelopejs/interface-dms/base/table-view";

const SUB_STATE = "$saas.invoice.sub_state";
const day = (date: Date) => ({ type: "date", value: date.toISOString(), format: "day" }) as const;

@Listable()
@Column({
  name: "$saas.invoices.column.status",
  type: statusType("invoice"),
  display: new DefaultDisplays.StatusPillDisplay({
    tones: { draft: "neutral", open: "info", paid: "success", void: "neutral", uncollectible: "error" },
    subField: "statusDetail",
    subTone: "muted",
  }),
  size: 200,
})
declare status: InvoiceStatus;

@Listable(["status", "attemptCount", "nextPaymentAttemptAt", "dueAt"])
get statusDetail(): CellSubline | null {
  if (this.status === "open" && this.attemptCount) {
    return this.nextPaymentAttemptAt
      ? { text: { key: `${SUB_STATE}.retry`, params: { date: day(this.nextPaymentAttemptAt) } }, tone: "error" }
      : { text: `${SUB_STATE}.retries_over`, tone: "error" };
  }
  if (this.status === "open" && this.dueAt) {
    return { text: { key: `${SUB_STATE}.due`, params: { date: day(this.dueAt) } } };
  }
  if (this.status === "uncollectible") return { text: `${SUB_STATE}.written_off`, tone: "error" };
  return null;
}
```

```json [frontend-vue/i18n/locales/saas-en-GB.json]
{
  "saas": {
    "invoice": {
      "sub_state": {
        "retry": "Payment failed · retry {date}",
        "retries_over": "Payment failed · no retry left",
        "due": "Due {date}",
        "written_off": "Written off"
      }
    }
  }
}
```

### Two lines without an avatar

`TwoLineDisplay` draws the column's value in its column's own format — a select's label, an amount, a date — over a sub-line. `primaryField` draws a row field's text instead, for a column whose value is not what it reads ("Renews in 3 days" over a `renewsAt` date the column sorts and filters by). Both lines are read even when the value is empty.

```ts [src/data-api/workspaces.ts]
// "Business" over "€29.00 × 23 seats / month"
@Column({ name: "$saas.workspaces.column.plan", type: new DefaultDataTypes.StringType(),
  display: new DefaultDisplays.TwoLineDisplay({ subField: "planDetail" }) })
declare planName: string | null;

@Listable(["planUnitAmountMinor", "currency", "seats", "planInterval"])
get planDetail(): ComposedText | null {
  if (!this.currency) return null;
  return {
    key: "$saas.workspaces.plan_cell.price_times_seats", // "{price} × {count} seat / {interval} | {price} × {count} seats / {interval}"
    params: {
      price: { type: "money", value: this.planUnitAmountMinor, currency: this.currency },
      count: { type: "count", value: this.seats },
      interval: { key: `$saas.workspaces.interval.${this.planInterval}` },
    },
  };
}

// "€49.00" over "At risk" in red, under a money column
@Column({ name: "$saas.workspaces.column.mrr", type: new MoneyCentsType(),
  display: new DefaultDisplays.TwoLineDisplay({ subField: "mrrNote" }) })
declare mrrMinor: number;

// "Renews in 3 days" over "Oct 12, 2026", red when the workspace will be suspended
@Column({ name: "$saas.workspaces.column.renews", type: new DefaultDataTypes.DateType(),
  display: new DefaultDisplays.TwoLineDisplay({ primaryField: "renewalSummary", subField: "renewalDate" }) })
declare renewsAt: Date | null;

@Listable(["renewalKind", "renewsAt"])
get renewalSummary(): ComposedText | null {
  if (!this.renewalKind || !this.renewsAt) return null;
  return { key: `$saas.workspaces.renewal.${this.renewalKind}`, params: { count: { type: "count", value: daysUntil(this.renewsAt) } } };
}

@Listable(["renewalKind", "renewsAt"])
get renewalDate(): CellSubline | null {
  if (!this.renewsAt) return null;
  return {
    text: { key: "$saas.workspaces.renewal.date", params: { date: { type: "date", value: this.renewsAt.toISOString() } } },
    tone: this.renewalKind === "suspends" ? "error" : undefined,
  };
}
```

A credit note's reason over its internal memo is a select column with `TwoLineDisplay({ subField: "internalMemo" })`; an owner's name over "Invitation pending" in its tone is `TwoLineDisplay({ subField: "ownerState" })` with `ownerState` a `CellSubline`.

### An identity without a value

`emptyLabel` and `emptyIcon` stand for a row without a value: a credit note no operator issued reads "Automatic", muted, next to a robot tile, where the others show the operator's avatar and name.

```ts
@Column({
  name: "$saas.credit_notes.column.issued_by",
  type: new DefaultDataTypes.StringType(),
  display: new DefaultDisplays.IdentityDisplay({ emptyLabel: "$saas.credit_notes.automatic", emptyIcon: "i-ph-robot" }),
})
get issuedBy(): string | null { /* ... */ }
```

## A display of your own

A module declares a display in two halves joined by an id of the form `<module>:<id>`.

**Backend** — a class extending `ColumnDisplay<Options>`, registered with `@RegisterDisplay`:

```ts [src/displays/last-runs.ts]
import { ColumnDisplay, RegisterDisplay } from "@antelopejs/interface-dms/base/table-view";

@RegisterDisplay("automation:last-runs")
export class LastRunsDisplay extends ColumnDisplay<{ limit?: number }> {}

@Listable()
@Column({ name: "Last runs", type: new DefaultDataTypes.StringType(), display: new LastRunsDisplay({ limit: 12 }) })
declare lastRuns: string;
```

**Frontend** — a data type registered under the same id (`useDataTypes().registerDataType({ id: "automation:last-runs", formatter })`), whose formatter draws the cell. It receives the display's options, plus the column's own type options as `typeOptions` (a select's items, for instance) and the id of the column's own type as `columnType`, and the row. See [Custom data types](/docs/extending-the-dashboard/custom-data-types#cell-data-types) for the formatter's signature.

Registration of the table throws for a display whose class was never decorated with `@RegisterDisplay`: its cells would otherwise fall back to the column's type without a word. Name a module's display `<module>:<id>`: the unprefixed ids are the DMS's own.

::note
A plain `{ type, options }` object is not a display: `display` only takes a `ColumnDisplay` instance.
::
