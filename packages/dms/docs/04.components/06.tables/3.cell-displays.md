# Cell displays

A column renders its cells through its data type's formatter. `display` on `@Column` draws the grid cells (and the fields of [expandable rows](/docs/components/tables#expandable-rows)) another way: a member as an avatar and a name, a status as a tinted pill, three counters as a progress bar. The column keeps its `type` for its forms, filters, validation and exports, and one label, its `name`.

A display is a typed class, like a data type: its options are checked at compile time, and its formatter receives the whole row, so a cell can compose sibling fields.

## Usage

```ts [src/data-apis/job-runs.ts]
import { DefaultDisplays } from "@antelopejs/interface-dms/base/table-view";

@Listable()
@Column({
  name: "Status",
  type: new DefaultDataTypes.SelectType({ items: JOB_RUN_STATUSES }),
  filterable: true,
  display: new DefaultDisplays.StatusPillDisplay({
    tones: { healthy: "success", running: "info", degraded: "warning", failing: "error" },
    subField: "lastError",
    liveValues: ["running"],
  }),
  size: 220,
})
declare status: JobRunStatus;

@Listable()
@Column({
  name: "Steps",
  type: new DefaultDataTypes.NumberType({ min: 0 }),
  display: new DefaultDisplays.ProgressDisplay({
    doneField: "doneSteps",
    totalField: "totalSteps",
    errorField: "failedSteps",
  }),
})
declare doneSteps: number;
```

A field a display reads (`lastError`, `totalSteps`) must be `@Listable()` to reach the row; give it `isVisible: false` on its own `@Column`, or no column at all, to keep it out of the grid. `size` sets the column's default width in px (150 otherwise; the room left is spread in proportion).

## Built-in displays

Every class lives in `DefaultDisplays` (`@antelopejs/interface-dms/base/table-view`):

| Class                 | Options                                                                                                                                                                                                 | Draws                                                                              |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `IdentityDisplay`     | `avatarField` (image value or URL), `icon` (tile instead of an avatar), `subtitleField`, `selfField` + `selfLabel` (tag of the signed-in user's row), `badges: [{ field, equals?, notEquals?, label, tone? }]`, `storage` | Avatar or icon tile, the value as the name, a "You" tag, badges, a secondary line. |
| `PillsDisplay`        | `labelKey` (a related row's label field, `name` by default), `exclusive: { field, label, icon? }` (one filled pill when the row's field is set), `emptyLabel`                                           | A list as outline pills; an unresolved relation id is skipped.                     |
| `RelativeDateDisplay` | `style` (`"relative"`, the default, or `"day"`), `tone`, `nowWithinMs` + `nowLabel`, `emptyLabel` + `emptyTone`, `soonWithinMs` + `soonTone`, `pastStyle` + `pastTone`, `byField` + `byLabel` (`{ date, name }`) | "2 hr. ago", "Active now", "In 5 days", "Sep 27 · by Camille".                    |
| `IndicatorDisplay`    | `onLabel`, `offLabel`, `onIcon`, `offIcon`, `onTone` (`success`), `offTone` (`dimmed`)                                                                                                                  | An icon and a word; on for a set flag or a non-empty list.                         |
| `StatusPillDisplay`   | `tones` (value → `Tone`, required; a value left out is neutral), `subField` (a line under the pill, in its tone), `liveValues` (values with a pulsing dot)                                                | A tinted pill led by a dot; a select column's item label and icon name it.         |
| `ProgressDisplay`     | `doneField`, `totalField` (required), `errorField`                                                                                                                                                      | A bar of the items done and "31 / 44", failed items in red at its end; green once all are done. |
| `SparklineDisplay`    | `field` (a list of numbers, required), `tone` (`primary`)                                                                                                                                               | A small line chart ("last 30 days").                                               |
| `DurationDisplay`     | `unit` (`"ms"`, the default, or `"s"`)                                                                                                                                                                  | "910 ms", "1.8 s", "4 min 12 s".                                                   |
| `BytesDisplay`        | —                                                                                                                                                                                                       | "12 kB", "1.4 MB".                                                                 |
| `MonoDisplay`         | `copy` (a button copying the value)                                                                                                                                                                     | The value in the mono font: ids, codes, slugs.                                     |

Labels are `$`-prefixed i18n keys or literals. Cell tones (`tone`, `onTone`…) are `default`, `muted`, `dimmed`, `highlighted`, `success`, `warning`, `error`, `info` and `primary`; the status pill, the sparkline and the identity badges take a `Tone` (`neutral`, `primary`, `secondary`, `success`, `warning`, `error`, `info`).

## A display of your own

A module declares a display in two halves joined by an id of the form `<module>:<id>`.

**Backend** — a class extending `ColumnDisplay<Options>`, registered with `@RegisterDisplay`:

```ts [src/displays/last-runs.ts]
import { ColumnDisplay, RegisterDisplay } from "@antelopejs/interface-dms/base/table-view";

@RegisterDisplay("automation:last-runs")
export class LastRunsDisplay extends ColumnDisplay<{ limit?: number }> {}

@Listable()
@Column({ name: "Last runs", type: new DefaultDataTypes.StringType(), display: new LastRunsDisplay({ limit: 12 }) })
declare lastRuns: string;
```

**Frontend** — a data type registered under the same id (`useDataTypes().registerDataType({ id: "automation:last-runs", formatter })`), whose formatter draws the cell. It receives the display's options, plus the column's own type options as `typeOptions` (a select's items, for instance), and the row. See [Custom data types](/docs/extending-the-dashboard/custom-data-types#cell-data-types) for the formatter's signature.

Registration of the table throws for a display whose class was never decorated with `@RegisterDisplay`: its cells would otherwise fall back to the column's type without a word. Name a module's display `<module>:<id>`: the unprefixed ids are the DMS's own.

::note
A plain `{ type, options }` object is not a display: `display` only takes a `ColumnDisplay` instance. See the [migration guide](/docs/building/migration-0-3-to-0-4) for 0.3 columns.
::
