# Rows ordered by hand

Pipeline stages, menu items, a roadmap: some lists have an order only a person decides. `reorder` puts a drag handle in front of each row of the grid; moving a row saves its new position in a number column.

```ts [src/pages/roadmap.ts]
static features = TableView(featureDataAPI, {
  caption: "Roadmap",
  reorder: { field: "position" },
  rowActions: { add: true, edit: true, delete: true },
});
```

```ts [src/data/features.ts]
@Listable()
@Sortable()
@Column({ name: "Position", type: new DefaultDataTypes.NumberType(), isVisible: false })
@Access(AccessMode.ReadWrite)
declare position: number;
```

## Requirements

`reorder: { field }` names the column holding a row's position. Registration throws unless:

- the column is a `NumberType` column,
- it is `@Sortable()` — the rows are listed sorted on it,
- it is writable (not `AccessMode.ReadOnly`) — moving a row edits it,
- the table keeps its `edit` action (`rowActions.edit` is not `false`).

## How a move is saved

The rows are listed sorted on `field`, ascending, and the sort picker is off. A move updates the page at once, then saves through the controller's edit route (`PUT <location>/edit?id=…`, a partial edit of `field` alone) **only the rows whose position changed**: the moved row takes the value halfway between its new neighbours (or one step beyond the only one, at an edge); when they leave no room — equal values, or none set — the page is renumbered from its lowest position, and still only the rows that changed are sent. A save that fails shows a toast and lists the rows again.

A row moves within the page shown: to move it further, raise the page size.

## When the handle is off

The handle shows on the grid display only, and only to a caller who may edit the rows: a reader gets the rows in their order, without the handle column. It is disabled while a search, a filter or a tab narrows the rows — positions are only meaningful over the whole list, and its tooltip asks to clear them.

## Keyboard

The handle is a button: with it focused, the **↑** and **↓** arrow keys move the row up and down.
