`HStack` lays its children out left to right, `VStack` top to bottom. `alignment` sets the cross axis, `distribution` shares the free space along the main axis, and `spacing` is the gap between children. A `Spacer` between children absorbs the leftover space: logo · `Spacer` · actions pins the logo left and the actions right.

## `HStack`

::block-playground{type="HStack" height="120"}
---
options:
  alignment: center
  distribution: start
  spacing: 12px
  wrap: false
children:
  - id: live
    type: LiveToggle
    options:
      variant: pill
  - id: spacer
    type: Spacer
  - id: period
    type: PeriodSelector
    options:
      id: sales
      defaultPreset: last-30-days
      variant: segmented
      presets: [last-7-days, last-30-days, last-90-days]
---
::

```ts fragment [src/pages/overview.ts]
import { HStack, Spacer } from "@antelopejs/interface-dms/base/stack";
import { LiveToggle } from "@antelopejs/interface-dms/base/live-toggle";
import { PeriodSelector } from "@antelopejs/interface-dms/base/period-selector";

static toolbar = HStack({ alignment: "center" })
  .child("live", LiveToggle())
  .child("spacer", Spacer())
  .child("period", PeriodSelector({ id: "sales" }));
```

## `VStack`

```ts fragment [src/pages/overview.ts]
import { VStack } from "@antelopejs/interface-dms/base/stack";

static column = VStack({ alignment: "stretch", spacing: "12px" })
  .child("notice", Banner({ tone: "info", size: "sm", title: "Numbers refresh every 15 minutes." }))
  .child("body", Placeholder({ label: "Content" }));
```

## Spacer

A `Spacer` is a flexible gap that works in either stack direction, and holds an empty cell in a [`GridRow`](/docs/components/layout-and-containers/grid).

::block-playground{type="HStack" height="100"}
---
options:
  spacing: 8px
children:
  - id: title
    type: Placeholder
    options:
      label: Logo
      width: 120px
      height: 48px
  - id: spacer
    type: Spacer
    options:
      grow: 1
  - id: actions
    type: Placeholder
    options:
      label: Actions
      width: 160px
      height: 48px
---
::

## Recipes

### Share a row between panels

A stack fills the width of what holds it, except inside an `HStack`: there sibling stacks share the row equally, or by their `grow`. A sidebar at `grow: 1` beside a content column at `grow: 3` takes a quarter of the row. In a row holding a `Spacer`, sibling stacks keep their content width so the spacer can push them aside.

### Equal-height cards

`alignment: "stretch"` makes children fill the cross axis, which gives a row of cards one height.

## Pitfalls

- `wrap` exists on `HStack` only.
- A `Spacer` respects its `minSize` / `maxSize` bounds: a `maxSize` that is too small leaves the remaining space unused.
