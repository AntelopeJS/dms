# Card

`Card` frames other blocks under one head: an eyebrow `title`, a mono `count`, a dim `description` line and link buttons on the right. Its children stack in the body, and an optional muted band closes it. Use it when several blocks read as one panel — a list and its toolbar, a meter and its legend.

::block-playground{type="Card" height="280"}
---
options:
  title: Connectors
  count: 4
  description: Data sources synced into the workspace.
  padded: false
  footer: Last sync 10:15
  actions:
    - label: View all
      to: /integrations
      icon: i-ph-arrow-right
children:
  - id: list
    type: KeyValueList
    options:
      card: false
      dense: true
      items:
        - label: Stripe
          value: Connected
          type: status
          tone: success
        - label: HubSpot
          value: Syncing
          type: status
          tone: info
        - label: Google Ads
          value: Token expired
          type: status
          tone: error
        - label: Postgres
          value: Connected
          type: status
          tone: success
---
::

## Usage

```ts fragment [src/pages/integrations.ts]
import { Card } from "@antelopejs/interface-dms/base/card";
import { KeyValueList } from "@antelopejs/interface-dms/base/key-value-list";

static connectors = Card({
  title: "Connectors",
  count: 4,
  padded: false,
  actions: [{ label: "View all", to: "/integrations", icon: "i-ph-arrow-right" }],
  footer: "Last sync 10:15",
}).child("list", KeyValueList({ card: false, dense: true, fetchUrl: "/api/connectors" }));
```

## Slots

Children added with `.child()` and no slot stack in the body. Two slots hold one block each:

| Slot      | Where it renders                                 |
| --------- | ------------------------------------------------ |
| `actions` | In the head, next to the link buttons.           |
| `footer`  | In the foot band, in place of the `footer` text. |

```ts [src/pages/integrations.ts]
import { Card, KeyValueList } from "@antelopejs/interface-dms/base";
import { HStack } from "@antelopejs/interface-dms/base/stack";
import { LiveToggle } from "@antelopejs/interface-dms/base/live-toggle";

Card({ title: "Connectors" })
  .child("list", KeyValueList({ card: false, fetchUrl: "/api/connectors" }))
  .child("sync", HStack().child("live", LiveToggle()), { slot: "footer" });
```

## Pitfalls

- Blocks that draw their own card (`KeyValueList`, `ActivityFeed`, `EmptyState`, `Section`) take `card: false` inside a `Card`, or you get a card in a card.
- Each slot holds one child. Put several blocks in an `HStack` first.
- Set `padded: false` for a list or a table that should run edge to edge.
