# Placeholder

`Placeholder` draws a dashed, patterned box with its `label` centered. It fetches nothing: use it to block out a layout before the real blocks exist, then swap each one for its real builder.

::block-playground{type="Placeholder" height="160"}
---
options:
  label: Revenue chart
  height: 120px
---
::

## Usage

```ts fragment [src/pages/scaffold.ts]
import { Placeholder } from "@antelopejs/interface-dms/base/placeholder";

static chart = Placeholder({ label: "Revenue chart", height: "240px" });
```

## Options

::block-options{type="Placeholder"}
::

Without `height`, the box fills its grid cell; without `width`, it fills its column.
