# Grid

`Grid` lays its rows out as a CSS grid. Each `GridRow` is a row, and its children spread across equal-width columns. The column count follows the densest row, so a two-item row and a three-item row align to one three-column track. Columns never shrink below `minColumnWidth`: on a narrow screen the grid drops columns and the cells wrap, down to one column on a phone.

::block-playground{type="Grid" height="300"}
---
options:
  gap: 1rem
  minColumnWidth: 220px
children:
  - id: kpis
    type: GridRow
    children:
      - id: revenue
        type: KpiCard
        options:
          title: Revenue
          valueFormat: currency
          currencyCode: EUR
          staticValue: 48200
          staticDelta: 12.4
          showDelta: true
      - id: orders
        type: KpiCard
        options:
          title: Orders
          staticValue: 1284
          staticDelta: 3.1
          showDelta: true
  - id: notes
    type: GridRow
    children:
      - id: left
        type: Placeholder
        options:
          label: Sales chart
          height: 120px
      - id: middle
        type: Placeholder
        options:
          label: Top products
          height: 120px
      - id: right
        type: Placeholder
        options:
          label: Activity
          height: 120px
---

## Usage

A `Grid`'s direct children must be `GridRow`s; the blocks go inside the rows.

```ts [src/pages/dashboard.ts]
import { Grid, GridRow } from "@antelopejs/interface-dms/base/grid";
import { KpiCard } from "@antelopejs/interface-dms/base/kpi-card";
import { ChartCard } from "@antelopejs/interface-dms/base/chart-card";
import { ChartArea } from "@antelopejs/interface-dms/base/chart";

static dashboard = Grid({ minColumnWidth: "240px" })
  .child(
    "kpis",
    GridRow()
      .child("revenue", KpiCard({ title: "Revenue", fetchUrl: "/api/sales/revenue", periodScope: "sales" }))
      .child("orders", KpiCard({ title: "Orders", fetchUrl: "/api/sales/orders", periodScope: "sales" })),
  )
  .child(
    "charts",
    GridRow().child(
      "sales",
      ChartCard({ title: "Sales", fetchUrl: "/api/sales/series", periodScope: "sales", chart: ChartArea() }),
      { colSpan: 2 },
    ),
  );
```

## Options

::block-options{type="Grid"}
::

`GridRow()` takes no options: it is a row marker. Its children accept one piece of child metadata, `colSpan`:

::block-playground{type="GridRow" height="160"}
---
children:
  - id: wide
    type: Placeholder
    colSpan: 2
    options:
      label: Spans two columns
      height: 100px
  - id: narrow
    type: Placeholder
    options:
      label: One column
      height: 100px
---
::

::block-options{type="GridRow"}
::

| Child metadata | Type     | Purpose                                                                                   |
| -------------- | -------- | ----------------------------------------------------------------------------------------- |
| `colSpan`      | `number` | Columns the cell spans. Never more than the columns left at the current width.            |

## Recipes

### Line cells up with a spacer

A [`Spacer`](/docs/components/layout-and-containers/stacks#spacer) in a row holds an empty cell, so the next cells line up with the columns above. Once the grid has dropped columns there is nothing to line up with, so the spacer hides instead of taking a row of its own.

### Nest any block

Any block may sit in a row, including stacks, tabs or a nested grid. The responsive behavior is pure CSS (container queries on the grid's own width), so the server-rendered page is already laid out the way the browser keeps it.

Only a grid's own rows share its columns. A `GridRow` placed inside a cell, for instance inside a `Section` that groups a few KPI cards, lays out its own children: two cards fill the cell on two columns, whatever the column count of the outer grid, and the outer grid's column count does not grow with it. Its tracks keep the default `240px` floor and a `1rem` gap. To line several rows up inside a cell, wrap them in a `Grid` of their own.

```ts [src/pages/overview.ts]
static overview = Grid().child(
  "groups",
  GridRow()
    .child("reach", Section({ title: "Reach" }).child("kpis", GridRow().child("sent", sent).child("delivered", delivered)))
    .child("engagement", Section({ title: "Engagement" }).child("kpis", GridRow().child("opened", opened).child("clicked", clicked)))
    .child("health", Section({ title: "Health" }).child("kpis", GridRow().child("bounced", bounced).child("complaints", complaints))),
);
```

## Pitfalls

::warning
Put blocks inside a `GridRow`, never directly under `Grid`. The block catalog declares `GridRow` as the only child `Grid` accepts, so the page editor and the dms-ai assistant refuse anything else, and the grid only lays out its rows.
::

- A `colSpan: 3` cell on a phone takes the single column rather than pushing the row off screen. Do not rely on spans for meaning.
