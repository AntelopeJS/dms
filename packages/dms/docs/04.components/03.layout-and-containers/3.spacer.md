`Spacer` takes the free space between its neighbors. In an [`HStack`](/docs/components/layout-and-containers/stacks) it grows sideways, and in a `VStack` it grows downward. Put one between the title and the actions of a toolbar, and the title stays left while the actions move to the right edge.

::block-playground{example="Spacer" height="100"}
::

## Usage

```ts fragment [src/pages/installations.ts]
import { HStack, Spacer } from "@antelopejs/interface-dms/base/stack";
import { LiveToggle } from "@antelopejs/interface-dms/base/live-toggle";
import { PeriodSelector } from "@antelopejs/interface-dms/base/period-selector";

static toolbar = HStack({ alignment: "center" })
  .child("live", LiveToggle())
  .child("spacer", Spacer())
  .child("period", PeriodSelector({ id: "production" }));
```

## Behavior

- `grow` is the spacer's share of the free space, 1 by default. Two spacers at `grow: 1` and `grow: 2` take one third and two thirds of it.
- `minSize` and `maxSize` bound the spacer in both directions. They set its minimum and maximum width and height.
- A spacer adds no gap of its own. The stack's `spacing` applies once between the spacer's neighbors, so they sit `spacing` apart when there is no free space to fill.
- In a [`GridRow`](/docs/components/layout-and-containers/grid), a spacer holds an empty cell, so the next cells line up with the grid's columns. When the grid has fewer columns than its widest row, as on a phone, the spacer hides.

## Pitfalls

- A `maxSize` smaller than the free space leaves the rest of it to the stack's `distribution`.
- Inside an `HStack` that holds a spacer, sibling stacks keep their content width so the spacer can push them aside. Without a spacer, they share the row by their `grow`.
