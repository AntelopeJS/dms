`Tab` draws a tab strip and a panel area. Each item has a `label` and a `slot`, plus an optional `icon`, `badge`, `avatar`, keyboard `shortcut` and `disabled` state. The open tab shows the children added with the matching `{ slot }`.

::block-playground{type="Tab" height="260"}
---
options:
  variant: link
  persistState: true
  items:
    - label: Overview
      slot: overview
      icon: i-ph-info
    - label: Tasks
      slot: members
      icon: i-ph-list-checks
      badge: 7
    - label: Invoices
      slot: invoices
      icon: i-ph-receipt
      badge: 3
children:
  - id: overview
    slot: overview
    type: KeyValueList
    options:
      items:
        - label: Project
          value: CH-0104
        - label: Status
          value: Active
          type: status
          tone: success
        - label: Inverter
          value: SE70112
          type: mono
  - id: members
    slot: members
    type: Placeholder
    options:
      label: Tasks table
      height: 120px
  - id: invoices
    slot: invoices
    type: Placeholder
    options:
      label: Invoices table
      height: 120px
---
::

## Usage

```ts fragment [src/pages/workspace.ts]
import { Tab } from "@antelopejs/interface-dms/base/tab";

static tabs = Tab({
  items: [
    { label: "Overview", slot: "overview" },
    { label: "Members", slot: "members" },
    { label: "Invoices", slot: "invoices" },
  ],
  persistState: true,
})
  .child("overview", KeyValueList({ fetchUrl: "/api/workspaces/{{params.id}}/summary" }), { slot: "overview" })
  .child("members", TableView(MembersDataAPI, { caption: "Members" }), { slot: "members" })
  .child("invoices", TableView(InvoicesDataAPI, { caption: "Invoices" }), { slot: "invoices" });
```

## Options

::block-options{type="Tab"}
::

`Color`, `Size` and `AxeOrientation` come from `@antelopejs/interface-dms/base/types`. A text `badge` takes a `$` key or a [composed text](/docs/components/block-fundamentals#composed-texts); a number shows as is.

## Recipes

### Count what each tab holds

Set `badgesUrl` to a route answering every count in one request, keyed by slot. Each value replaces that tab's static `badge`, drawn as a mono counter like a table view's tab counts. The route is read again when one of the tab set's watch actions fires, when the page refreshes its blocks, and on each event of `realtimeTopic`.

```ts fragment [src/pages/workspace.ts]
static tabs = Tab({
  items: [
    { label: "Overview", slot: "overview" },
    { label: "Members", slot: "members", badge: "…" },
    { label: "Invoices", slot: "invoices", badge: "…" },
  ],
  badgesUrl: "/api/workspaces/{{params.id}}/tab-counts", // answers { members: 12, invoices: 1284 }
});
```

### Link to a tab

With `persistState`, the open tab is kept in the URL by its slot (`?tab=invoices`), so a reload or a shared link opens it. The first tab writes nothing, and a URL naming a tab by its index (`?tab=2`) still opens it. `stateKey` renames the query parameter.

### Keep short pill tabs compact

`fit: true` keeps a horizontal `pill` list to its labels' width instead of stretching it across a wide card.

## Pitfalls

- The item's `slot` and the child's `slot` must match exactly, or the panel stays empty.
- `unmountOnHide` defaults to `true`: a hidden panel's blocks are destroyed and fetch again when shown. Set it to `false` to keep them alive.
- Tabs emit `TabEvents.TAB_CHANGE`, which other blocks can watch ([Actions & reactivity](/docs/building/actions-and-reactivity#events-components-emit)).
