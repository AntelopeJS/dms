Layout blocks render no data of their own. They arrange **other** blocks into a screen: the [forms](/docs/components/forms), [tables](/docs/components/tables) and [charts and widgets](/docs/components/charts-and-widgets) of a page. You nest them with `.child()` ([Block fundamentals](/docs/components/block-fundamentals#composing-blocks)), and each nested position keeps its own permission.

::block-playground{type="Grid" height="260"}
---
options:
  gap: 1rem
  minColumnWidth: 200px
children:
  - id: kpis
    type: GridRow
    children:
      - id: revenue
        type: KpiCard
        options:
          title: Revenue
          valueFormat: currency
          currencyCode: EUR
          staticValue: 48200
          staticDelta: 12.4
          showDelta: true
      - id: orders
        type: KpiCard
        options:
          title: Installations
          staticValue: 37
          staticDelta: 3.1
          showDelta: true
      - id: churn
        type: KpiCard
        options:
          title: Quote refusals
          valueFormat: percent
          staticValue: 0.18
          staticDelta: -8.5
          showDelta: true
          invert: true
---
::

## Pick a container

| Block | Use it to | Page |
| ----- | --------- | ---- |
| `Grid` + `GridRow` | Lay blocks out in responsive rows and columns, as on a dashboard. | [Grid](/docs/components/layout-and-containers/grid) |
| `HStack`, `VStack` | Line blocks up in a row or a column: toolbars, side-by-side panels. | [Stacks](/docs/components/layout-and-containers/stacks) |
| `Spacer` | Push neighbors apart in a stack, or hold an empty cell in a grid row. | [Spacer](/docs/components/layout-and-containers/spacer) |
| `PageToolbar` | Start a page with a period or live data: its scope, the last update, Live / Pause and the period, the same on every page. | [Page toolbar](/docs/components/layout-and-containers/page-toolbar) |
| `Card` | Frame several blocks under one titled head, with head actions and a footer. | [Card](/docs/components/layout-and-containers/card) |
| `Tab` | Show one panel at a time, each panel holding its own blocks. | [Tabs](/docs/components/layout-and-containers/tabs) |
| `Guard` | Replace a group of blocks with one empty state when a route says there is nothing. | [Guard](/docs/components/layout-and-containers/guard) |
| `Placeholder` | Block out a layout before the real blocks exist. | [Placeholder](/docs/components/layout-and-containers/placeholder) |

For settings screens, [`Section` and `FieldRow`](/docs/components/lists-and-settings/section) are containers too.

## Compose a screen

Containers nest freely. Here a `Grid` row splits a page into a file list and a tabbed detail panel, each blocked out with a `Placeholder` until its real block exists:

```ts fragment [src/pages/workspace.ts]
import { Grid, GridRow } from "@antelopejs/interface-dms/base/grid";
import { Placeholder } from "@antelopejs/interface-dms/base/placeholder";
import { Tab } from "@antelopejs/interface-dms/base/tab";

static layout = Grid({ gap: "1rem" }).child(
  "main",
  GridRow()
    .child("files", Placeholder({ label: "Files" }))
    .child(
      "detail",
      Tab({
        items: [
          { label: "Overview", icon: "i-ph-info", slot: "overview" },
          { label: "Settings", icon: "i-ph-gear", slot: "settings" },
        ],
      })
        .child("overview", Placeholder({ label: "Overview" }), { slot: "overview" })
        .child("settings", Placeholder({ label: "Settings" }), { slot: "settings" }),
    ),
);
```

::tip
A role needs every level it should render. Granting `layout` alone does not show `layout.main.files`: each nested id is its own line in the roles editor.
::
