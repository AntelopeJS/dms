# Lists & settings

These blocks cover what a settings screen or an overview needs beyond charts and tables: a feed of recent events, a bar telling how much of a quota is used, and the titled sections whose rows hold a label, its help text and a control. The core settings pages of the DMS are built from them.

::block-playground{type="Section" height="260"}
---
options:
  title: Plan & usage
  description: Seats, storage and API calls of the workspace.
children:
  - id: seats
    type: FieldRow
    options:
      label: Seats
      description: Billed monthly.
      layout: form
    children:
      - id: meter
        type: Meter
        options:
          max: 10
          value: 8
          warnAt: 80
  - id: storage
    type: FieldRow
    options:
      label: Storage
      layout: form
    children:
      - id: meter
        type: Meter
        options:
          max: 50
          value: 38.2
          valueLabel: 38.2 / 50 GB
---
::
