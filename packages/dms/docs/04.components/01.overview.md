# Overview

The DMS ships a catalog of **components** you declare on the backend and the shared Inertia/Vue frontend renders them. For standard screens you write no Vue: you compose these builders and the frontend draws the result. This section is the reference for each one.

If you haven't yet seen _how_ components attach to a page, read [Pages & components](/docs/building/pages-and-components) first — this section is the per-component detail it points to.

## How to read each chapter

The component chapters follow the same shape, so you can scan them the same way — [Data types](/docs/components/data-types), [Data controller](/docs/components/data-controller), and [File storage](/docs/components/file-storage) are supporting references with their own structure:

- **What it renders** — the visual anatomy (what the user actually sees).
- **Usage** — the import and a minimal, real example.
- **Options** — the builder's options, from source.
- **Features** — the notable capabilities.
- **Permissions** — how the page's [Auth & permissions](/docs/auth-and-tenancy/auth-and-permissions) applies to it.
