title: "Code block"
description: Read-only code with syntax highlighting, a copy button and a height cap — static, or read from a route.

---

`CodeBlock` shows read-only code in the code editor's look: a head with the `title`, the language and a copy button, then the code highlighted. Long lines scroll sideways unless `wrap` is on, and `maxLines` caps the height. The code is written in the options, or read from a route that answers `{ code, language? }` — a generated snippet, a stored configuration, a request body.

::block-playground{type="CodeBlock" height="220"}
---
options:
  title: Field declaration
  language: typescript
  copy: true
  code: |
    static cover = Form({
      fields: [
        { id: "cover", label: "Cover", type: new DefaultDataTypes.ImageType({ multiple: false }) },
      ],
    });
---
::

## Usage

```ts fragment [src/pages/media.ts]
import { CodeBlock } from "@antelopejs/interface-dms/base/code-block";

static preset = CodeBlock({
  title: "$media.presets.config",
  language: "json",
  maxLines: 12,
  fetchUrl: "/api/media/presets/{{params.id}}/config",
});
```

## Options

::block-options{type="CodeBlock"}
::

A route may answer a language under a common alias — `js`, `ts`, `bash`, `sh`, `plain` — and the block reads it; an unknown one is shown as plain text. While the first answer loads the block draws placeholder lines; a failure shows an error with a retry, and a 404 the [not-found state](/docs/components/block-fundamentals#not-found).

## Pitfalls

- In a custom component, show code with the `DmsCodeSnippet` component rather than a `<pre>` and a copy button of your own.
