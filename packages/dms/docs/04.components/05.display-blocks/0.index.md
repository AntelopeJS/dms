Display blocks carry the summaries and notices around a page's data: a group of headline figures, label / value facts, a grid of cards linking elsewhere, an empty state, a banner and a read-only code snippet. Each one is a leaf block that reads its content from its options or from a route, and writes its texts in the reader's language ([Block fundamentals](/docs/components/block-fundamentals)).

## The blocks

::card-group
:::card{title="Stat group" icon="i-lucide-gauge" to="/docs/components/display-blocks/stat-group"}
Several figures or states at a glance.
:::

:::card{title="Key / value list" icon="i-lucide-list" to="/docs/components/display-blocks/key-value-list"}
Label and value rows, each value drawn by its type.
:::

:::card{title="Navigation cards" icon="i-lucide-layout-dashboard" to="/docs/components/display-blocks/nav-card-grid"}
Cards linking to other pages, with their live state.
:::

:::card{title="Empty state" icon="i-lucide-inbox" to="/docs/components/display-blocks/empty-state"}
Why there is nothing here, and what to do next.
:::

:::card{title="Banner" icon="i-lucide-megaphone" to="/docs/components/display-blocks/banner"}
A notice with a tone, actions and a remembered dismiss.
:::

:::card{title="Code block" icon="i-lucide-code" to="/docs/components/display-blocks/code-block"}
Read-only code with highlighting and a copy button.
:::
::

All of them import from the `base` barrel or their own subpath:

```ts [src/pages/overview.ts]
import {
  Banner,
  CodeBlock,
  EmptyState,
  KeyValueList,
  NavCardGrid,
  StatGroup,
} from "@antelopejs/interface-dms/base";
```
