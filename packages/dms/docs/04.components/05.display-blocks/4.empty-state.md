`EmptyState` centers an icon well, a title, a short explanation and the link buttons that fit the case. The `variant` says why the place is empty and sets the icon, the tone and how it is announced: `error` as an alert, the others as a status.

::block-playground{type="EmptyState" height="300"}
---
options:
  title: No email sent yet
  description: Send your first email from your module, then come back here to follow its delivery.
  variant: no-data
  hatched: true
  code:
    language: typescript
    content: 'await sendMail({ to: "ada@example.com", template: "welcome" });'
  actions:
    - label: Read the guide
      to: /docs/mailing
      icon: i-ph-book-open
---
::

## Usage

```ts fragment [src/pages/invoices.ts]
import { EmptyState } from "@antelopejs/interface-dms/base/empty-state";

static noInvoices = EmptyState({
  title: "$billing.invoices.empty_title",
  description: "$billing.invoices.empty_description",
  actions: [{ label: "$billing.invoices.create", to: "/invoices/new", icon: "i-ph-plus" }],
});
```

## Options

::block-options{type="EmptyState"}
::

| `variant`   | Use it when                                  |
| ----------- | -------------------------------------------- |
| `no-data`   | Nothing exists yet. The default.             |
| `no-result` | A search or a filter matched nothing.        |
| `no-access` | The viewer may not see what is here.         |
| `error`     | Something failed; announced as an alert.     |

## Recipes

### Show it only when the data says so

To show an empty state in place of other blocks, such as a record with no traffic yet instead of empty charts, wrap those blocks in a [`Guard`](/docs/components/layout-and-containers/guard) and give it these options as `fallback`.

### Start with a snippet

A first-run screen shows the call to make with `code`, drawn as a [code block](/docs/components/display-blocks/code-block) with its copy button (`copy: false` drops it).

## Pitfalls

- Inside a `Card` or a `Section`, set `card: false`.
- The first action leads (solid); the others follow in a quieter style.
