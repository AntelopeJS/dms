# Hero

`Hero` opens a landing or onboarding page: a small-capitals `eyebrow`, a display-size headline (`title`) that may run over two lines, a `lead` paragraph, up to three `actions`, a few `proof` figures under the lead, and an `image` or an icon composition (`icons`) beside or under the texts. Every text takes a string — `$`-prefixed for an i18n key — or a [composed text](/docs/components/block-fundamentals#composed-texts).

::block-playground{type="Hero" height="380"}
---
options:
  eyebrow: Customer portal
  title: Every order, *one place*
  lead: Follow orders from checkout to delivery, and answer customers in seconds.
  actions:
    - label: Open orders
      to: /orders
      icon: i-ph-package
    - label: Read the guide
      to: https://example.com/guide
  proof:
    - value: 2 min
      label: to set up
    - value: 99.9 %
      label: uptime last year
  icons:
    - i-ph-package
    - i-ph-truck
    - i-ph-smiley
  background: gradient
---

## Usage

```ts [src/pages/home.ts]
import { Hero } from "@antelopejs/interface-dms/base/hero";

static hero = Hero({
  eyebrow: "$home.hero.eyebrow",
  title: "$home.hero.title", // "Every order, *one place*"
  lead: "$home.hero.lead",
  actions: [
    { label: "$home.hero.start", to: "/orders/orders-list" },
    { label: "$home.hero.guide", to: "https://example.com/guide" },
  ],
  proof: [
    { value: "2 min", label: "$home.hero.setup" },
    { value: { key: "home.hero.teams", params: { count: 1240 } }, label: "$home.hero.daily" },
  ],
  image: "/media/files/onboarding.png",
  imageAlt: "$home.hero.image_alt",
  background: "card",
});
```

## Highlighted words

The words of the headline wrapped in `*asterisks*` are drawn in the theme's primary colour — "Every order, *one place*". The asterisks travel with the translation, so each language highlights its own words. When the headline marks none, `highlight` names them: its first occurrence in the headline is highlighted.

## Media

- **`image`** — a public URL, or the URL of a file from the media library. Give it an `imageAlt`; without one the image is decorative and hidden from screen readers. An image wins over `icons`.
- **`icons`** — up to three icons, drawn as tiles leaning on each other: a light illustration when there is no picture.
- **`mediaPosition`** — `side` (default) puts the media beside the texts from the `lg` breakpoint; `below` puts it under them. On a phone it always comes under the texts.

## Look

| Option | Values |
| ------ | ------ |
| `align` | `left` (default), `center` — the texts, the actions and the figures line up together |
| `size` | `lg` (default) for a landing page, `md` for a section opener |
| `background` | `plain` (default) on the page itself, `gradient` a soft wash of the primary colour, `card` a bordered card |

The colours come from the theme tokens, so the hero follows the light and dark modes and a project's primary colour. The first action leads (solid), the others are outlined; an action's own `variant` and `color` override that.

## Accessibility

The headline is an `h2` naming the section (`aria-labelledby`); the figures are a description list, each value with its label; the icon composition is decorative.

## Pitfalls

- Keep the headline short: past two lines, write the rest in the `lead`, or in a [`Prose`](/docs/components/display-blocks/prose) block under the hero.
- `actions` and `proof` are capped (3 and 4): a page that needs more links wants a [`NavCardGrid`](/docs/components/display-blocks/nav-card-grid), more figures a [`StatGroup`](/docs/components/display-blocks/stat-group).
