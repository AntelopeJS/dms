`ChartBar` compares categories with bars. Its default orientation is horizontal, which leaves room for long category labels; set `orientation: "vertical"` or use a [column chart](/docs/components/charts-and-widgets/charts/column) for periods.

::block-playground{type="ChartBar" height="320"}
---
options:
  title: Tickets by team
  height: 240px
  roundedCorners: true
  staticDataset:
    - name: Open
      data:
        - x: Billing
          y: 42
        - x: Onboarding
          y: 31
        - x: Integrations
          y: 27
        - x: Security
          y: 12
---
::

## Usage

```ts fragment [src/pages/dashboard.ts]
import { ChartBar } from "@antelopejs/interface-dms/base/chart";

static tickets = ChartBar({
  title: "$support.tickets.by_team",
  fetchUrl: "/api/support/tickets-by-team",
  stacked: true,
});
```

The route answers `{ series }` in the shape listed under [Data shapes](/docs/components/charts-and-widgets/charts#data-shapes). Wrap the chart in a [`ChartCard`](/docs/components/charts-and-widgets/chart-card) to add a headline value and a comparison.

## Recipes

### Stack statuses

`stacked: true` piles the series of each category into one bar: open, pending and closed tickets per team.
