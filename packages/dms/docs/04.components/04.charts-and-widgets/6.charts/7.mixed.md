---
title: "Mixed chart"
description: Lines, areas, columns and range bands sharing one axis, one type per series.
mode: reference
---

`ChartMixed` draws each series with its own type on one shared x axis: columns for volume, a line for a rate, a band for a range. `seriesDefs` names each series' type and color.

::block-playground{type="ChartMixed" height="320"}
---
options:
  title: Quotes and site visits
  height: 260px
  seriesDefs:
    - name: Quotes
      type: column
    - name: Visits
      type: line
  staticDataset:
    - name: Quotes
      data: [21, 26, 38, 44, 52, 46]
    - name: Visits
      data: [1400, 1650, 2300, 2900, 3100, 2800]
---
::

## Usage

```ts fragment [src/pages/dashboard.ts]
import { ChartMixed } from "@antelopejs/interface-dms/base/chart";
import { ChartType } from "@antelopejs/interface-dms/base/chart-type";

static funnel = ChartMixed({
  title: "$shop.funnel.orders_and_visits",
  fetchUrl: "/api/shop/funnel",
  seriesDefs: [
    { name: "Orders", type: ChartType.COLUMN },
    { name: "Visits", type: ChartType.LINE, color: "info" },
  ],
});
```

The route answers `{ series }` in the shape listed under [Data shapes](/docs/components/charts-and-widgets/charts#data-shapes). Wrap the chart in a [`ChartCard`](/docs/components/charts-and-widgets/chart-card) to add a headline value and a comparison.

## Recipes

### A band with a median

Declare one series as `ChartType.RANGE_AREA` and another as `ChartType.LINE` to draw a percentile band with its median on top.
