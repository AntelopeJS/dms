# Scatter chart

`ChartScatter` places each point by two measures — deal size against cycle length, response size against latency. Points are drawn at 6 px unless `pointSize` says otherwise.

::block-playground{type="ChartScatter" height="320"}
---
options:
  title: Deal size vs. cycle length
  height: 260px
  xaxisType: numeric
  pointSize: 8
  showLabels: true
  rawOptions:
    - key: xaxis.min
      value: "0"
    - key: xaxis.max
      value: "60"
  staticDataset:
    - name: Won
      data:
        - x: 12
          y: 4200
          label: Acme
        - x: 30
          y: 9800
          label: Globex
        - x: 21
          y: 6100
          label: Initech
        - x: 45
          y: 15200
          label: Umbrella
---
::

## Usage

```ts fragment [src/pages/dashboard.ts]
import { ChartScatter } from "@antelopejs/interface-dms/base/chart";

static deals = ChartScatter({
  title: "$crm.deals.size_vs_cycle",
  fetchUrl: "/api/crm/deals/scatter",
  xaxisType: "numeric",
  showLabels: true,
});
```

The route answers `{ series }` in the shape listed under [Data shapes](/docs/components/charts-and-widgets/charts#data-shapes). Wrap the chart in a [`ChartCard`](/docs/components/charts-and-widgets/chart-card) to add a headline value and a comparison.

## Recipes

### Label the points

With `showLabels`, a point's `label` is what its data label shows; a point without one shows its value.
