# Range area chart

`ChartRangeArea` plots a band per series instead of a curve: each point is `{ x, y: [low, high] }`. Percentile bands read as one distribution when you send adjacent ranges — `p50 – p95`, then `p95 – p99`.

::block-playground{type="ChartRangeArea" height="320"}
---
options:
  title: Latency distribution
  height: 240px
  fillOpacity: 0.35
  staticDataset:
    - name: p50 – p95
      data:
        - x: Mon
          y: [120, 210]
        - x: Tue
          y: [132, 245]
        - x: Wed
          y: [118, 230]
        - x: Thu
          y: [140, 280]
        - x: Fri
          y: [151, 310]
---
::

## Usage

```ts fragment [src/pages/dashboard.ts]
import { ChartRangeArea } from "@antelopejs/interface-dms/base/chart";

static distribution = ChartRangeArea({
  title: "$api.metrics.latency_distribution",
  fetchUrl: "/api/metrics/latency-bands",
  fillOpacity: 0.35,
});
```

The route answers `{ series }` in the shape listed under [Data shapes](/docs/components/charts-and-widgets/charts#data-shapes). Wrap the chart in a [`ChartCard`](/docs/components/charts-and-widgets/chart-card) to add a headline value and a comparison.

## Recipes

### A band with a line on top

`rangeArea` is also a valid `seriesDefs` type of a [mixed chart](/docs/components/charts-and-widgets/charts/mixed), so a band can carry a plain median line.
