---

`ChartArea` fills the space under each line. Use it when the volume matters as much as the trend, and `stacked: true` to show how series add up to a total.

::block-playground{type="ChartArea" height="320"}
---
options:
  title: Traffic by channel
  height: 240px
  stacked: true
  fillOpacity: 0.4
  staticDataset:
    - name: Organic
      data: [320, 340, 360, 410, 430, 470, 520]
    - name: Paid
      data: [120, 160, 150, 180, 220, 210, 260]
    - name: Referral
      data: [60, 70, 65, 80, 95, 90, 110]
---
::

## Usage

```ts fragment [src/pages/dashboard.ts]
import { ChartArea } from "@antelopejs/interface-dms/base/chart";

static traffic = ChartArea({
  title: "$marketing.traffic.by_channel",
  fetchUrl: "/api/marketing/traffic",
  periodScope: "marketing",
  stacked: true,
  fillOpacity: 0.4,
});
```

The route answers `{ series }` in the shape listed under [Data shapes](/docs/components/charts-and-widgets/charts#data-shapes). Wrap the chart in a [`ChartCard`](/docs/components/charts-and-widgets/chart-card) to add a headline value and a comparison.

## Recipes

### Inside a chart card

`ChartArea` is the usual chart of a [chart card](/docs/components/charts-and-widgets/chart-card): `ChartCard({ …, chart: ChartArea({ comparisonStyle: "dashed" }) })`.
