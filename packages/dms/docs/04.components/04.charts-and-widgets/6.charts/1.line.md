`ChartLine` draws one line per series over a category, datetime or numeric x axis. Use it for a trend over time, such as requests, revenue or latency, and its comparison series for the previous period.

::block-playground{type="ChartLine" height="320"}
---
options:
  title: Response time
  height: 240px
  curve: smooth
  strokeWidth: 2
  annotations:
    - y: 300
      label: SLO
      color: error
  staticDataset:
    - name: p50
      data: [120, 132, 118, 140, 151, 138, 129]
    - name: p95
      data: [210, 245, 230, 280, 310, 265, 240]
---
::

## Usage

```ts fragment [src/pages/dashboard.ts]
import { ChartLine } from "@antelopejs/interface-dms/base/chart";

static latency = ChartLine({
  title: "$api.metrics.latency",
  fetchUrl: "/api/metrics/latency",
  periodScope: "api",
  xaxisType: "datetime",
  curve: "smooth",
  annotations: [{ y: 300, label: "SLO", color: "error" }],
  syncGroup: "metrics",
});
```

The route answers `{ series }` in the shape listed under [Data shapes](/docs/components/charts-and-widgets/charts#data-shapes). Wrap the chart in a [`ChartCard`](/docs/components/charts-and-widgets/chart-card) to add a headline value and a comparison.

## Recipes

### Steps instead of curves

`curve: "stepline"` draws a value that changes by steps (replicas, plan limits). `curve` wins over `smooth` when both are set.

### Read a stacked grid together

Give every chart of a metrics grid the same `syncGroup`: hovering one moves the tooltip of all of them.
