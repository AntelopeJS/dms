`ChartRadialBar` draws each record as a ring filled to its value, in percent. Use it for the progress of a few measures towards a goal — onboarding steps, quotas — with `showTotal` to label the middle with the chart's title and total.

::block-playground{type="ChartRadialBar" height="320"}
---
options:
  title: Onboarding completion
  height: 280px
  hollowSize: 45%
  showTotal: true
  staticDataset:
    - label: Profile
      value: 92
    - label: Team invited
      value: 64
    - label: First import
      value: 38
---
::

## Usage

```ts fragment [src/pages/dashboard.ts]
import { ChartRadialBar } from "@antelopejs/interface-dms/base/chart";

static onboarding = ChartRadialBar({
  title: "$app.onboarding.completion",
  fetchUrl: "/api/onboarding/completion",
  showTotal: true,
});
```

The route answers `{ series }` in the shape listed under [Data shapes](/docs/components/charts-and-widgets/charts#data-shapes). Wrap the chart in a [`ChartCard`](/docs/components/charts-and-widgets/chart-card) to add a headline value and a comparison.
