# Pie chart

`ChartPie` draws parts of a whole as slices and always labels them. Prefer a [donut](/docs/components/charts-and-widgets/charts/donut) when a total belongs in the middle.

::block-playground{type="ChartPie" height="320"}
---
options:
  title: Traffic sources
  height: 260px
  legendPosition: bottom
  staticDataset:
    - label: Organic
      value: 52
    - label: Paid
      value: 26
    - label: Referral
      value: 14
    - label: Direct
      value: 8
---
::

## Usage

```ts [src/pages/dashboard.ts]
import { ChartPie } from "@antelopejs/interface-dms/base/chart";

static sources = ChartPie({
  title: "$marketing.traffic.sources",
  fetchUrl: "/api/marketing/traffic/sources",
});
```

The route answers `{ series }` in the shape listed under [Data shapes](/docs/components/charts-and-widgets/charts#data-shapes). Wrap the chart in a [`ChartCard`](/docs/components/charts-and-widgets/chart-card) to add a headline value and a comparison.

### Keep slices few
