# Radar chart

`ChartRadar` draws one polygon per series over spokes, one spoke per measure. Use it to compare a few items on several measures — plans by feature, teams by skill. It draws its own polygon grid, not the horizontal grid lines of the axis charts.

## Usage

```ts [src/pages/dashboard.ts]
import { ChartRadar } from "@antelopejs/interface-dms/base/chart";

static plans = ChartRadar({
  title: "$saas.plans.comparison",
  fetchUrl: "/api/saas/plans/radar",
  fillOpacity: 0.25,
});
```

The route answers `{ series }` in the shape listed under [Data shapes](/docs/components/charts-and-widgets/charts#data-shapes). Wrap the chart in a [`ChartCard`](/docs/components/charts-and-widgets/chart-card) to add a headline value and a comparison.

## Recipes

### Keep it to a few series

Beyond three or four polygons the radar stops reading. Split the comparison, or use a [column chart](/docs/components/charts-and-widgets/charts/column).
