# Column chart

`ChartColumn` draws vertical columns. Use it to compare periods (orders per month) or a handful of categories, with `stacked: true` to show their composition.

::block-playground{type="ChartColumn" height="320"}
---
options:
  title: Orders per month
  height: 240px
  columnWidth: 60
  roundedCorners: true
  staticDataset:
    - name: Orders
      data:
        - x: May
          y: 820
        - x: Jun
          y: 910
        - x: Jul
          y: 870
        - x: Aug
          y: 1020
        - x: Sep
          y: 1140
        - x: Oct
          y: 1284
---
::

## Usage

```ts [src/pages/dashboard.ts]
import { ChartColumn } from "@antelopejs/interface-dms/base/chart";

static orders = ChartColumn({
  title: "$shop.orders.per_month",
  fetchUrl: "/api/shop/orders-per-month",
  columnWidth: 60,
});
```

The route answers `{ series }` in the shape listed under [Data shapes](/docs/components/charts-and-widgets/charts#data-shapes). Wrap the chart in a [`ChartCard`](/docs/components/charts-and-widgets/chart-card) to add a headline value and a comparison.

## Recipes

### Months or days on a datetime axis

With `xaxisType: "datetime"`, a series whose points fall on the first of each month — or on whole days — draws one column per month (or day), evenly spaced, under a single label: `Aug '26`, or `xAxis.datetimeFormat` when set (`"MMM"`). A month the route leaves out keeps its empty slot, stacked or not, and the tooltip names the whole month. A date is a day when it is a date-only string (`"2026-10-01"`) or a midnight, the browser's or UTC's (`"2026-10-01T00:00:00Z"`). Weekly or quarterly points, and points with a time of day, keep the time-scaled axis.

```ts [src/pages/revenue.ts]
ChartColumn({ stacked: true, xaxisType: "datetime", fetchUrl: "/api/revenue/by-plan" });
// series: [{ name: "Pro", data: [{ x: "2026-08-01", y: 4200 }, { x: "2026-09-01", y: 4800 }] }, …]
```

### Columns with a target

Add `annotations: [{ y: 1200, label: "Target" }]` to draw the goal across the columns.
