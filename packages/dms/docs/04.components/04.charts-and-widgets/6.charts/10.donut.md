`ChartDonut` draws parts of a whole on a ring, with an optional central label and sub-label. Its data is a list of `{ label, value }` records.

::block-playground{type="ChartDonut" height="320"}
---
options:
  title: Accounts by plan
  height: 260px
  centralLabel: "1,284"
  centralSubLabel: accounts
  legendPosition: bottom
  staticDataset:
    - label: Free
      value: 712
    - label: Starter
      value: 341
    - label: Business
      value: 189
    - label: Enterprise
      value: 42
---
::

## Usage

```ts fragment [src/pages/dashboard.ts]
import { ChartDonut } from "@antelopejs/interface-dms/base/chart";

static plans = ChartDonut({
  title: "$saas.accounts.by_plan",
  fetchUrl: "/api/saas/accounts/by-plan",
  centralLabel: "$saas.accounts.total",
});
```

The route answers `{ series }` in the shape listed under [Data shapes](/docs/components/charts-and-widgets/charts#data-shapes). Wrap the chart in a [`ChartCard`](/docs/components/charts-and-widgets/chart-card) to add a headline value and a comparison.

## Recipes

### Labels on the slices

A donut labels each slice only when the ring can hold the text: from `arcWidth: 35` up. The default ring shows none; the legend and the tooltip carry the values.
