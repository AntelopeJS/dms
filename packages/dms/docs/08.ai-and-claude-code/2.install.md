# Install in Claude Code

Claude Code reads skills from the `antelopejs` plugin. The plugin brings the framework skills and keeps `.claude/skills/` in sync with the skills your installed packages ship, including the DMS and every `dms-*` module.

::steps{level="3"}
### Add the plugin

Run these two commands once, from any terminal:

::::code-group
```bash [Terminal]
claude plugin marketplace add AntelopeJS/claude-antelopejs
claude plugin install antelopejs@antelopejs
```

```text [Inside Claude Code]
/plugin marketplace add AntelopeJS/claude-antelopejs
/plugin install antelopejs@antelopejs
```
::::

### Open your project

Start Claude Code in a directory holding an `antelope.config.*` file. On session start, the plugin scans `node_modules` and `.antelope/cache` for packages declaring `antelopeJs.skills`, and links each skill into `.claude/skills/<package>--<skill>` — for the DMS, `dms--dms-pages`, `dms--dms-best-practices` and the others.

### Keep building

The sync runs again after every Bash command, so a `pnpm install` or an `ajs` run that adds a module brings its skills in. Run `/antelopejs:sync-skills` to sync by hand and see what changed.
::

## Projects created from a template

[template-dms-demo](https://github.com/AntelopeJS/template-dms-demo) and [template-dms-adonis](https://github.com/AntelopeJS/template-dms-adonis) ship a `.claude/settings.json` that declares the marketplace and enables the plugin. Claude Code offers to install it the first time you open the project: accept, and there is nothing else to do.

```json [.claude/settings.json]
{
  "extraKnownMarketplaces": {
    "antelopejs": {
      "source": { "source": "github", "repo": "AntelopeJS/claude-antelopejs" }
    }
  },
  "enabledPlugins": {
    "antelopejs@antelopejs": true
  }
}
```

Add the same file to an existing project to give every contributor the same prompt.

## What the sync touches

- It creates one **relative symlink** per skill, so the skill always matches the installed package version.
- It records its entries in `.claude/skills/.ajs-managed.json` and adds a scoped `.gitignore`, so your repository stays clean.
- It never touches a skill it did not create. A name collision with one of yours is reported and skipped.
- Outside an AntelopeJS project it does nothing.

::tip
Ask Claude Code "which DMS skills do you have?" after installing: it lists the linked skills and what each one is for.
::
