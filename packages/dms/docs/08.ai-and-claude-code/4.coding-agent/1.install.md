---
title: "Install the plugin"
description: Add the AntelopeJS plugin to Claude Code or Codex, so your agent gets the AntelopeJS DMS skills, then connect it to the DMS MCP tools.
mode: how-to
---

Your coding agent needs the `antelopejs` plugin to get the AntelopeJS DMS skills. The plugin comes from the [AntelopeJS/agent-skills](https://github.com/AntelopeJS/agent-skills) repository. It links the skills your installed packages ship into the project, and adds its own skills for pages, mockups and existing databases. The [skill catalog](/docs/ai-and-claude-code/coding-agent/skill-catalog) lists them all.

The DMS AI assistant in the dashboard does not need the plugin. See [In the DMS AI assistant](/docs/ai-and-claude-code/dms-assistant).

## Add the plugin

Run these commands once. The plugin installs in your user scope, so every project sees it.

::tabs
:::tabs-item{label="Claude Code" icon="i-lucide-terminal"}
```bash [Terminal]
claude plugin marketplace add AntelopeJS/agent-skills
claude plugin install antelopejs@antelopejs
```

Inside a session, the same commands are `/plugin marketplace add AntelopeJS/agent-skills` and `/plugin install antelopejs@antelopejs`.

Restart the session, or run `/reload-plugins`. The plugin's hooks then sync the skills into `.claude/skills/`.

To install the plugin for one repository only, add `--scope project` to both commands. Claude Code then records it in that repository's `.claude/settings.json`.
:::

:::tabs-item{label="Codex" icon="i-lucide-code"}
```bash [Terminal]
codex plugin marketplace add AntelopeJS/agent-skills
codex plugin add antelopejs@antelopejs
```

You can also install `antelopejs` from `/plugins` in Codex, or from the plugins directory of the desktop app.

Then open `/hooks` in Codex and trust the `antelopejs` entries. Codex runs a plugin's hooks only once you trust them, and asks again after each plugin update. The trusted hooks sync the skills into `.agents/skills/`.

Until you trust the hooks, run the sync yourself from the project root, and again after you install or upgrade packages:

```bash [Terminal]
npx -y github:AntelopeJS/agent-skills sync --target codex
```
:::
::

::note
The sync also works without the plugin. `npx -y github:AntelopeJS/agent-skills sync` links the skills into both `.claude/skills/` and `.agents/skills/`, where any agent that reads those folders finds them.
::

## Connect the agent to the DMS tools

Start the project once in development:

```bash [Terminal]
ajs project dev
```

`@antelopejs/dms` then adds a `dms` server to the project's `.mcp.json` for Claude Code and to `.codex/config.toml` for Codex. Approve the `dms` server in Claude Code, or trust the project in Codex. Your agent then has the builder, database, page and mockup tools that the DMS AI assistant uses. [MCP server](/docs/ai-and-claude-code/mcp-and-tools/mcp-server) describes both entries and the tools.

## Check that the skills are there

Run `/antelopejs:skills` in Claude Code, or `$antelopejs:skills` in Codex. It lists the synced skills and the package each one comes from.

If no DMS skill shows, the packages are not installed yet:

1. Run `pnpm install`.
2. Run `ajs project dev` once. The modules that `antelope.config.ts` declares arrive in `.antelope/cache`.
3. Run `/antelopejs:sync-skills`.

In Claude Code, run `/reload-skills` when `.claude/skills/` did not exist at the start of the session.

## Projects created from a template

[`template-dms-demo`](https://github.com/AntelopeJS/template-dms-demo) and [`template-dms-adonis`](https://github.com/AntelopeJS/template-dms-adonis) ship a `.claude/settings.json` that declares the marketplace and enables the plugin. Once you trust the folder, Claude Code offers to install the plugin. Accept it. The `AGENTS.md` of each template gives Codex the sync command.

To give every Claude Code contributor the same prompt in an existing project, commit this file:

```json [.claude/settings.json]
{
  "extraKnownMarketplaces": {
    "antelopejs": {
      "source": { "source": "github", "repo": "AntelopeJS/agent-skills" }
    }
  },
  "enabledPlugins": {
    "antelopejs@antelopejs": true
  }
}
```

## Update the plugin

The synced skills follow your packages, not the plugin. Upgrade `@antelopejs/dms` or a module, and the next sync points at the new version. To update the plugin's own skills:

::tabs
:::tabs-item{label="Claude Code" icon="i-lucide-terminal"}
```bash [Terminal]
claude plugin marketplace update antelopejs
claude plugin update antelopejs@antelopejs
```
:::

:::tabs-item{label="Codex" icon="i-lucide-code"}
```bash [Terminal]
codex plugin marketplace upgrade antelopejs
```

Then trust the hooks again in `/hooks`.
:::
::

## Remove the plugin

::tabs
:::tabs-item{label="Claude Code" icon="i-lucide-terminal"}
```bash [Terminal]
claude plugin uninstall antelopejs@antelopejs
claude plugin marketplace remove antelopejs
```

If you installed it for one repository, add `--scope project` to `uninstall`, and remove the two keys from that repository's `.claude/settings.json`.
:::

:::tabs-item{label="Codex" icon="i-lucide-code"}
```bash [Terminal]
codex plugin remove antelopejs@antelopejs
codex plugin marketplace remove antelopejs
```
:::
::

To remove the synced skills from a project, delete the entries that `.claude/skills/.ajs-managed.json` and `.agents/skills/.ajs-managed.json` list. Then delete those two files and the `.gitignore` next to each.
