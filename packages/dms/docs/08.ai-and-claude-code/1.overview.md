A skill is a short instruction file that an agent loads when a task matches its description. AntelopeJS ships skills for the framework, the DMS and each module you install. They tell the agent how to declare a page, which block draws what, how permissions work and how to run the dev servers. The same skills serve [Claude Code](https://claude.com/claude-code) and [Codex](https://developers.openai.com/codex) in your terminal, and the [`dms-ai` assistant](/docs/ai-and-claude-code/dms-ai) inside your dashboard.

::tip
Start with [Install the plugin](/docs/ai-and-claude-code/install). The [skill catalog](/docs/ai-and-claude-code/skill-catalog) lists every skill you can get.
::

## Each skill ships with the code it describes

A skill lives in the package whose code it describes, so it changes with that code and the project gets the version it installed. A package declares its skill folders under `antelopeJs.skills` in its `package.json`. Three layers of packages ship skills:

| Layer | Package | Skills |
| ----- | ------- | ------ |
| Framework | `@antelopejs/core` | `antelopejs`, `ajs-cli`, `ajs-consume-interface`, `ajs-author-interface` |
| DMS | `@antelopejs/dms` and `@antelopejs/dms-frontend` | `dms`, `dms-project`, `dms-module`, `dms-auth` from `@antelopejs/dms`. `dms-frontend` from `@antelopejs/dms-frontend`, for the `ajs dms` CLI and frontend modules. |
| Modules | Each `dms-*` module and some interface packages | One skill per module, such as `dms-mailing` or `dms-media`. `@antelopejs/dms-ai` ships four. |

The `antelopejs` plugin for Claude Code and Codex comes from the [AntelopeJS/agent-skills](https://github.com/AntelopeJS/agent-skills) repository. It ships none of the skills above. It links them from your installed packages into the project, and adds skills of its own that run the sync, list the synced skills, look up interface contracts, scaffold a module and evaluate skills. It also ships the DMS page-building skills `antelopejs:dms-pages` and `antelopejs:dms-best-practices`.

## How skills reach your agent

In Claude Code and Codex, [install the `antelopejs` plugin](/docs/ai-and-claude-code/install) once. It links every package's skills into `.claude/skills/` for Claude Code and `.agents/skills/` for Codex.

In the dashboard, the [`dms-ai` assistant](/docs/ai-and-claude-code/dms-ai) needs nothing installed. It loads the skills of every loaded module and of the project's dependencies.
