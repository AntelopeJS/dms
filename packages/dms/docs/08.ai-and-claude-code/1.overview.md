# AI & Claude Code

The DMS is built to be developed with an AI agent. A suite of **skills** — short, versioned instructions an agent loads on demand — teaches it the framework, the DMS and every module you install: how to declare a page, which block draws what, how permissions are derived, how to run the dev servers. The same skills serve [Claude Code](https://claude.com/claude-code) in your terminal and the [dms-ai assistant](/docs/ai-and-claude-code/dms-ai) inside your dashboard.

## Three layers, no duplicates

Each skill lives next to the code it describes, so it ships and versions with it.

| Layer | Where it lives | What it teaches |
| ----- | -------------- | --------------- |
| **Framework** | The `antelopejs` Claude Code plugin ([claude-antelopejs](https://github.com/AntelopeJS/claude-antelopejs)) | AntelopeJS itself: the core, the `ajs` CLI, interfaces as versioned contracts. It also **syncs** the skills the other two layers ship. |
| **DMS** | `@antelopejs/dms`, in its `skills/` folder | Projects, pages and blocks, auth, distributable modules, the dev servers, and the best practices. |
| **Modules** | Each `dms-*` module, declared in its `package.json` | When and how to use that module: the AI assistant, the builder, mailing, media… |

## The DMS skills

| Skill | Reach for it to |
| ----- | --------------- |
| `dms` | Get the mental model and be routed to the right skill. |
| `dms-project` | Set up a project that uses the DMS: `antelope.config.ts`, lifecycle, frontend. |
| `dms-pages` | Declare pages and compose blocks, data types and the routes that feed them. |
| `dms-auth` | Protect routes and pages, register permissions, work with users, roles and tenants. |
| `dms-module` | Package a distributable DMS module. |
| `dms-dev` | Start, stop or restart the backend and frontend dev servers. |
| `dms-best-practices` | Describe pages as blocks, build only the missing custom block, give it `.meta()`, and follow the design-fidelity protocol. |

## How skills reach your agent

::card-group
:::card{title="Claude Code" icon="i-lucide-terminal" to="/docs/ai-and-claude-code/install"}
Install the `antelopejs` plugin once; it links every package's skills into `.claude/skills/`.
:::

:::card{title="dms-ai assistant" icon="i-lucide-bot" to="/docs/ai-and-claude-code/dms-ai"}
Nothing to install: the assistant loads the skills of every loaded module.
:::
