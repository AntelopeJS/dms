[`@antelopejs/dms-assistant`](/docs/modules/assistant/introduction) adds a chat panel to the dashboard for the platform owner. A coding agent runs behind it in a local sidecar process. The agent reads the loaded modules, edits the project and shows its work in the chat. The assistant is a development tool. With `NODE_ENV=production`, the module starts no sidecar, and a sidecar you start yourself exits.

## Skills load without a plugin

The assistant needs no `antelopejs` plugin. When it starts, it collects the skills that `antelopeJs.skills` declares in three places:

- Every module the project loads.
- The dependencies of those modules.
- The project's own dependencies and devDependencies. The devDependencies bring the framework skills of `@antelopejs/core`.

The agent gets each skill as `<module>:<skill>`, such as `dms:dms-auth`. Install a module, and its skill is there on the next start. When two skills share a name, the assistant keeps one copy.

The **Use machine-local skills** setting also loads the skills in `~/.claude/skills` on your machine. Teammates and other environments do not get them.

## The agent shows blocks before it builds them

When a choice is visual, the agent shows it before it asks. Two examples are how a block will look, and whether a DMS block fits better than a custom one. The agent calls its `PreviewBlocks` tool with a tree of DMS blocks. The call can attach your design as a reference image and more trees as variants:

```json [PreviewBlocks input]
{
  "title": "KPI row",
  "description": "Your mockup's figures as DMS KPI cards.",
  "tree": {
    "type": "Grid",
    "children": [
      {
        "type": "GridRow",
        "children": [
          { "type": "KpiCard", "options": { "title": "Revenue", "staticValue": 48200, "valueFormat": "currency", "currencyCode": "EUR" } },
          { "type": "KpiCard", "options": { "title": "Orders", "staticValue": 1284 } }
        ]
      }
    ]
  },
  "reference": { "attachmentId": "mockup.png", "caption": "Your design" }
}
```

The chat shows an attachment card with a thumbnail. Click it to open a modal that draws the real blocks with your dashboard's theme, next to the reference image, with one tab per variant. A variant can also be a sketch: static HTML and CSS of the custom block the agent proposes, labelled as not a DMS block. You compare both before anyone writes code. The agent then asks its question with its `AskUser` tool, and you answer with a button.

The modal draws the blocks with `DmsBlockPreview`, the component behind the [block preview page](/docs/ai-and-claude-code/mcp-and-tools/block-preview-page). A dashboard without that component shows the tree as JSON instead.

The [chat walkthrough](/docs/modules/assistant/usage/chat#block-previews) shows the attachment and both kinds of variant, from a labelled demonstration conversation.
