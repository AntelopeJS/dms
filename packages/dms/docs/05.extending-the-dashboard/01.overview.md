Start with the built-in [components](/docs/components/overview). When one is missing, choose the smallest extension that supplies it. Most needs stop before a custom component:

| You need to                                 | Start here                                                                                                                                       |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Add a block to another module's page        | [Page extensions](/docs/building/pages-and-components#extending-another-modules-page). Built-in blocks need no frontend layer.                    |
| Add a message across dashboard pages        | [Layout banners](/docs/extending-the-dashboard/dashboard-chrome#layout-banners), registered on the backend.                                      |
| Change the logo, colors, or fonts           | [Theming and branding](/docs/extending-the-dashboard/theming-and-branding).                                                                      |
| Add a header button, a panel, or a widget   | A [frontend layer](/docs/building/frontend-layer) that calls the shell registries below.                                                         |
| Render UI the existing blocks cannot express | A [custom component](/docs/components/custom-component), composed with the existing blocks.                                                     |

## What a frontend layer can extend

A frontend layer registers each extension from a plugin, and the DMS renders it. [Frontend composables](/docs/frontend-composables/overview) covers the functions your Vue components call once they are registered.

| Extension               | Adds                                                                                                                       |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| [Dashboard chrome](/docs/extending-the-dashboard/dashboard-chrome)             | Header buttons, layout banners, command-palette groups, an assistant mode, docked side panels, footer links, and auth-page links. |
| [Widgets and overlays](/docs/extending-the-dashboard/widgets-and-overlays)     | Framed widgets in the bottom-left dock, free components in the sidebar, and free overlays on every page.                 |
| [Theming and branding](/docs/extending-the-dashboard/theming-and-branding)     | Your logo, palette, fonts, and design-token overrides.                                                                   |
| [Custom data types](/docs/extending-the-dashboard/custom-data-types)           | The Vue side of a field or column type that a backend `@RegisterDataType` declares.                                      |
| [TableView displays](/docs/extending-the-dashboard/table-view-displays)        | Another renderer for a table's body, such as a kanban board, cards, or a calendar.                                       |
| [Component events](/docs/extending-the-dashboard/component-events)             | Reactions of one component to the events of another.                                                                     |
| [Period filtering](/docs/extending-the-dashboard/period-filtering)             | A date range that several widgets share through a scope id.                                                              |
