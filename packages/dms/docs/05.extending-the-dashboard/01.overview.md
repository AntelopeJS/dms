# Overview

The DMS frontend renders backend-described pages out of the box. When you need to go beyond what the built-in [components](/docs/components/overview) cover, a **custom frontend module** ([Frontend layer](/docs/building/frontend-layer)) registers extra capabilities into the dashboard. This section is the catalog of those registration points — the [table below](#what-you-can-extend) lists them; the next section, [Frontend composables](/docs/frontend-composables/overview), covers the composables your layer's Vue _consumes_.

## What you can extend

| Extension              | Adds                                                                                     | Chapter                                                                  |
| ---------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **Dashboard chrome**   | Header buttons, command-palette groups, sidebar widgets, app widgets and overlays, footer links, auth-page links | [Dashboard chrome](/docs/extending-the-dashboard/dashboard-chrome)       |
| **Theming & branding** | Your logo, palette, fonts, and design-token overrides                                    | [Theming & branding](/docs/extending-the-dashboard/theming-and-branding) |
| **Custom data types**  | A new field/column type (the Vue behind a backend `@RegisterDataType`)                   | [Custom data types](/docs/extending-the-dashboard/custom-data-types)     |
| **TableView displays** | An alternate table body renderer (kanban, cards, calendar…)                              | [TableView displays](/docs/extending-the-dashboard/table-view-displays)  |
| **Component events**   | Cross-component reactivity — one component reacts to another's events                    | [Component events](/docs/extending-the-dashboard/component-events)       |
| **Period filtering**   | Link widgets to a shared date-range via a scope id                                       | [Period filtering](/docs/extending-the-dashboard/period-filtering)       |
