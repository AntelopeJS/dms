# Overview

Start with the built-in [components](/docs/components/overview). When something is missing, choose the smallest extension that supplies it:

| You need to… | Start here |
| --- | --- |
| Add a block to another module's page | [Page extensions](/docs/building/pages-and-components#extending-another-modules-page); no frontend layer is needed for built-in blocks. |
| Add a message across dashboard pages | [Layout banners](/docs/extending-the-dashboard/dashboard-chrome#layout-banners), registered on the backend. |
| Change the logo, colors, or fonts | [Theming & branding](/docs/extending-the-dashboard/theming-and-branding). |
| Add a header button, panel, or menu group | A [frontend layer](/docs/building/frontend-layer) using the shell registries below. |
| Render UI the existing blocks cannot express | One [custom component](/docs/components/custom-component), composed with the existing blocks. |

The table below lists the frontend extension points. [Frontend composables](/docs/frontend-composables/overview) covers the APIs your Vue components call after registration.

## What you can extend

| Extension              | Adds                                                                                     | Chapter                                                                  |
| ---------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **Dashboard chrome**   | Header buttons, layout banners, command-palette groups and assistant, sidebar widgets, app widgets and overlays, footer links, auth-page links | [Dashboard chrome](/docs/extending-the-dashboard/dashboard-chrome)       |
| **Theming & branding** | Your logo, palette, fonts, and design-token overrides                                    | [Theming & branding](/docs/extending-the-dashboard/theming-and-branding) |
| **Custom data types**  | A new field/column type (the Vue behind a backend `@RegisterDataType`)                   | [Custom data types](/docs/extending-the-dashboard/custom-data-types)     |
| **TableView displays** | An alternate table body renderer (kanban, cards, calendar…)                              | [TableView displays](/docs/extending-the-dashboard/table-view-displays)  |
| **Component events**   | Cross-component reactivity — one component reacts to another's events                    | [Component events](/docs/extending-the-dashboard/component-events)       |
| **Period filtering**   | Link widgets to a shared date-range via a scope id                                       | [Period filtering](/docs/extending-the-dashboard/period-filtering)       |
